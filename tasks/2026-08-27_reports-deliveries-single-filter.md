# Єдиний фільтр діапазону/місяця для вкладки «Доставки» у /reports

## Статус
done

## Задача
На `/reports?tab=deliveries` вибір місяця/діапазону вгорі має перераховувати всі
віджети вкладки одразу, без окремих кнопок. Раніше графіки «Звідки дізнались» /
«Хто кому купує» вимагали кліку по кнопці «Діапазон», а «Співвідношення типів
підписок» / «Співвідношення розмірів» завжди показували дані за весь час.

## Реалізація

### app/services/reports_service.py — `get_orders_data`
- Marketing, for-whom, delivery-type і size breakdown тепер фільтруються по
  `Order.created_at` через `range_filters`. Без діапазону — за весь час.
- Прибрано подвійний набір ключів `*_all` / `*_range`. Тепер один набір:
  `marketing_chart` / `marketing_total`, `for_whom_chart` / `for_whom_total`,
  `delivery_type_chart` / `delivery_type_total`, `size_chart` / `size_total`.
- Додано ключ `has_range`.
- `_monthly_orders_trend()` не змінювався — рухомий тренд за 365 днів.

### app/templates/reports/index.html
- Прибрано перемикач «Весь час / Діапазон» (`.report-switch`) з обох графіків.
- Підзаголовки карток показують «За <діапазон>» або «За весь час».
- Тотали й дані графіків беруться з нових одиничних ключів.
- Прибрано `bindSwitch`, `marketingDatasets`/`forWhomDatasets`, `switchMode`.
  `createSwitchableChart` / `createSwitchablePieChart` приймають плоский
  `{labels, values}`.

## Як тестувати
1. **Перезапустити web-контейнер** — gunicorn без `--reload`, інакше зміни не
   підхопляться: `docker compose restart web`.
2. `/reports?tab=deliveries` без фільтра → усі віджети за весь час, підзаголовки
   «За весь час», перемикача немає.
3. Обрати «Липень» (або `date_from=2026-07-01&date_to=2026-07-31`) → KPI,
   «Динаміка доставок», «Розподіл по містах», «Звідки дізнались», «Хто кому
   купує», «Співвідношення типів підписок», «Співвідношення розмірів» — усі за
   липень; тотали й підзаголовки «За 2026-07-01 — 2026-07-31».
4. «Динаміка нових замовлень / підписок» лишається за 365 днів (за домовленістю).

## Edge cases
- Місяць без замовлень → графіки показують «Немає даних…», тотал 0.
- Вказано лише `date_from` або лише `date_to` → фільтр однобічний, `range_label`
  показує одну дату.
- `Order.created_at` — datetime, `date_to <= 2026-07-31` відсікає час 31-го числа
  (існуюча конвенція `_build_date_filters`, не змінював).
