# Редагування розміру не синхронізується в доставку

## Статус
done

## Задача
Зміна поля «Розмір» (напр. M → L) — і в модалці «Редагувати замовлення`,
і в модалці «Редагувати підписку» — зберігалась на рівні `Order` /
`Subscription`, але на сторінці замовлень і у флориста розмір лишався старим (M).

## Root cause
Обидва сервіси синхронізують дані `order → delivery` для незавершених доставок і
копіюють багато полів (адреса, коментар, телефон, спосіб доставки, тип букета
тощо), але **не копіювали `delivery.size`**:
- `update_order` (`app/services/order_service.py`), цикл по активних доставках;
- `update_subscription` (`app/services/subscription_service.py`), внутрішній
  цикл по доставках замовлення.

Сторінка замовлень (`templates/orders/list.html:616`) і florist-роут
(`blueprints/orders/routes.py:1133`) показують `delivery.size or order.size`.
Оскільки `delivery.size` лишався непорожнім ('M'), нове значення ніколи не
відображалось. `Delivery` — джерело правди для розміру.

## Реалізація
- `app/services/order_service.py` — новий хелпер
  `sync_order_to_active_deliveries(order)` — єдина точка fan-out полів
  `order → delivery` для незавершених доставок (включно з `size`).
- `update_order` тепер: окремо ставить дату найранішій активній доставці +
  викликає хелпер.
- `update_subscription` (`app/services/subscription_service.py`) — замість
  власного дубльованого циклу викликає той самий хелпер (локальний імпорт,
  щоб уникнути циклічного). Поля спершу пишуться в `order.*` з `subscription.*`,
  потім хелпер розкидає їх у доставки.
- Без міграцій — колонки ті самі. Це рефакторинг + додано відсутнє поле `size`.
- `Delivery` не має колонки `custom_amount`, тож синхронізувати більше нічого.

## Як тестувати
1. Відкрити замовлення → «Редагувати» → змінити «Розмір» M → L → зберегти.
2. Те саме через модалку «Редагувати підписку».
3. На сторінці замовлень бейдж розміру = L (для всіх незавершених доставок
   підписки).
4. На сторінці флориста для цих доставок розмір = L.
5. Доставлені / скасовані доставки не змінюються.

## Edge cases
- Розмір «Власний» + `custom_amount` — `custom_amount` вже писався в `Order`;
  `Delivery` його не зберігає, ціна рахується з `Order`.
- Кілька активних доставок в одному замовленні — усі отримають новий розмір
  (узгоджено з поведінкою інших полів у тому ж циклі).
